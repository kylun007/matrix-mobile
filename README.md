# Matrix Mobile

Projeto de interface e recursos para usar o HaxBall em dispositivos móveis, com um aplicativo Android auxiliar.

## Conteúdo

- Interface mobile: `mobile-ui.js` e `mobile-ui.css`
- Recursos adicionais: `mobile-features.js`
- Cliente: `min.js`
- Aplicativo Android: diretório `android/`
- Testes de regressão do cliente: `tests/client-regressions.cjs`

Consulte [android/README.md](android/README.md) para instruções de compilação do aplicativo Android.
